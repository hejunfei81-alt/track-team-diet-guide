尽量少吃

偶尔解馋可以，常吃拖后腿。一周最多一次，别骗自己。

🍟

🧋

高糖冲垮血糖，训练没劲、下午犯困

🍜

🌭
香肠 · 烤肠 · 腊肉

分时段饮食规则

什么时候吃，比吃什么更讲究。点卡片看实操细节。

🌅 晨训前

喝半杯水 + 半根香蕉或一片面包垫底。

晨跑先别空腹上大强度，低血糖又伤胃。醒了先补水，15 分钟后再垫两口碳水。

🍚 训练前 1–2 小时

以易消化碳水为主，七分饱。

面条、香蕉、全麦面包都行。别碰高油高脂——消化慢，练着恶心、状态掉。

🍌 训练前 30 分钟

香蕉半根 / 一片面包垫底。

空腹上大强度容易低血糖，速度课直接垮。垫一口碳水，精神头完全不一样。

💧 训练中

长距离大汗时小口补电解质水。

短训补水就够，别硬灌运动饮料——糖太多，喝了犯困。长时间耐力训练才需要补糖补电解质。

🥛 训练后 30 分钟内

碳水 + 蛋白一起吃，黄金窗口。

牛奶/乳清 + 香蕉/面包，蛋白补 20–30g。错过这个点，恢复肉眼可见地变慢。

🍳 休息日

三餐照常，蛋白质不能断。

别拿"今天不练"当胡吃海塞的借口。肌肉修复在休息日，蛋白吃不够等于白练一周。

📈 赛前 3 天

开始逐步加碳水，饮食清淡。

米饭、面、意面往上加，肉照吃。从今天起戒外卖炸物，让肠胃适应干净饮食。

🍚 赛前 1 天

高碳水储备，饮食清淡。

不碰陌生食物、不碰辛辣——肠胃是赛场的一部分。晚上好好睡，别熬夜啃夜宵。

🏁 比赛当日

赛前 3 小时吃完正餐。

赛前 1 小时只吃香蕉/面包这类好消化的，赛前 30 分钟小口补水。上场前肚子不能空，也不能胀。

🌙 夜宵（晚训后）

小份蛋白 + 少量碳水。

牛奶/酸奶 + 鸡蛋就够。拒绝油炸和烧烤——大半夜的油脂全存进腰上。

目标食谱：增肌 × 减脂

先选目标，再看对应食谱。减脂要减脂肪，不是减肌肉、减成绩；增肌靠干净训练餐，不靠垃圾食品。

⚖️ 增肌 / 减脂通用策略

维持 / 增肌队员

  • 按训练量正常吃，碳水、蛋白质给足，不刻意少吃
  • 增肌 = 干净热量盈余 + 大重量训练，不是狂吃零食
  • 看每周体重趋势，别被一天的水分波动带节奏
  • 赛前阶段保持日常模式，不临时加戏

需要降体脂队员

  • 温和热量缺口（约 -300~-500 kcal/天），绝不极端
  • 蛋白质只增不减，保住肌肉才是保住成绩
  • 碳水总量控制，但训练前后必须补，别断碳
  • 蒸煮少油代替油炸外卖，选择干净的烹饪
  • 每周称重 + 量腰围，看趋势，不盯单日数字

⚠ 红线警告

  • 极端节食 = 自毁运动能力
  • 断碳水、只吃水煮菜、饿着训练——掉的是水分和肌肉，成绩和免疫力一起崩
  • 减脂永远是慢功夫，一周掉 0.5–1kg 是上限，稳着来

消炎恢复食物

慢性炎症是伤病的温床，消炎食物 = 恢复的加法。点卡片看 NRV，把这些加进日常餐盘。

🐟深海鱼

一周 2–3 次 · 三文鱼 / 沙丁鱼

Omega-3 天然抗炎，减训练后肌肉酸痛

🫒橄榄油

凉拌 / 低温炒，替代部分炒菜油

单不饱和脂肪酸，抗炎顺带护血管

🌰核桃 / 亚麻籽

每天一小把

植物 Omega-3，护关节抗炎症

🧡姜黄

炖菜 / 咖喱里放，配黑胡椒吸收翻倍

姜黄素缓解肌肉酸痛，日常随手加

🫚生姜

炒菜 / 泡水喝

减轻运动后肌肉酸痛，随手可用

🧄大蒜

切碎再下锅，香味抗炎双拿

大蒜素抗炎抗氧化，还能下饭

🍵绿茶

每天 1–2 杯，不加糖

茶多酚抗氧化，替代奶茶的第一步

🫐莓果

蓝莓 / 草莓，每天一小把

花青素抗氧化，练后吃恢复快

🍒樱桃

练后一小把当加餐

有研究支持能减轻运动后肌肉酸痛

🥦十字花科蔬菜

西兰花 / 白菜，每天一盘

萝卜硫素抗炎，配训练餐不挑嘴

🍅西红柿

做熟吃，茄红素吸收更好

茄红素抗炎抗氧化，番茄炒蛋就是好菜

🍍菠萝 / 木瓜

练后水果，别当正餐

天然蛋白酶助消化、促消肿

记住

消炎食物 ≠ 替代冰敷、拉伸和休息。先管好恢复基本功，再靠吃锦上添花。

运动补剂简易科普

按国际运动营养学会（ISSN）、IOC 共识的 A/B/C 证据等级排序。先吃好饭，再谈补剂。

A 类 · 证据最强（ISSN/IOC 明确支持，值得优先）

🥤 咖啡因

A 类 · 耐力+爆发
3–6 mg/kg，赛前 30–60 分钟，提升爆发力和耐力表现。下午别喝，影响睡眠。

💪 肌酸

A 类 · 力量+爆发
3–5 g/天，短期可冲 20 g/天×5–7 天。最有把握的力量类补剂，肌肉增重是水不是脂肪。

⚡ β-丙氨酸

A 类 · 短时高强度
2–5 g/天，分次服。60–240 秒高强度项目（400米以上）提升肌肽缓冲酸，有刺痒感正常。

🥛 蛋白质粉（乳清/酪蛋白/大豆）

A 类 · 恢复
练后 20–40 g，适合日常肉没吃够的人。属于"吃饭的补充"，不是必须。

🧪 甜菜汁

A 类 · 耐力+摄氧
300–500 mg 硝酸盐/天，有氧耐力项目有证据支持，连用数周效果更稳。血压偏低者慎用。

🧂 碳酸氢钠

A 类 · 抗酸缓冲
0.2–0.3 g/kg，赛前 60–90 分钟。1–4 分钟全力项目（400–800米）可延缓酸疲劳，胃肠道反应大，先试。

B 类 · 条件支持（看情况用）

☀️ 维生素 D

B 类 · 日常保养
日晒不足者普遍偏低，补它保骨骼、护免疫。按需服用，别自己加量。

🐟 鱼油 / Omega-3

B 类 · 消炎恢复
每周 2–3 次深海鱼即可，鱼油作为补充。抗炎，配合消炎食物板块一起用。

🦴 氨糖软骨素

B 类 · 关节保养
膝盖、踝关节有磨损感的队员可长期吃。见效慢，坚持才有意义。

⚙️ 亮氨酸

B 类 · 蛋白合成触发
配合蛋白质一起用，单独吃意义不大。多吃肉蛋奶就行。

🧲 铁

B 类 · 仅缺铁人群
缺铁性贫血才补（尤其长跑、女队员），先查血再说，别乱补。

🍃 锌

B 类 · 免疫+恢复
运动员常见偏低，不足时补。过量反而伤吸收，按需。

C 类 · 证据弱 / 看个体（不优先）

🍶 支链氨基酸 BCAA

C 类 · 可被蛋白替代
练后乳清/食物蛋白已含足量 BCAA，单独补基本是智商税。

🌿 左旋肉碱

C 类 · 基本无效
减脂帮助有限，白花钱。

🔥 燃脂类（CLA/绿咖啡等）

C 类 · 证据不足
减脂靠热量缺口，别指望这些。

💧 电解质片

C 类 · 看情况
长时间大出汗或热天训练才需要，平时白水就够。

🚫 避雷清单（伤害远大于收益）
✗
暴汗服 / 燃脂腰带

掉的是水分不是脂肪，还容易脱水中暑

✗
网红"排油胶囊"

拉肚子伤肠胃，不少还违规

✗
任何激素 / 睾酮类

违法，毁内分泌毁职业生涯，碰了就滚出队伍

✗
三无蛋白粉 / 增肌粉

成分不明，可能含违禁成分，一口毁掉职业生涯

⚠ 重要提醒

  • 补剂只是饮食的辅助工具，永远替代不了天然食物。先吃好饭，再谈补剂。
  • 禁止盲目叠加、大剂量服用——超量不涨成绩，只涨肝肾负担。
  • 赛前或服用前先问队医 / 教练，来源不明的产品一概不碰。

常见饮食误区

纠正认知，比多吃一口更重要。

✗
"不吃主食瘦得快"

碳水是运动燃料。断碳训练直接拉胯，成绩掉得比体重快。

✗
"练完不能吃饭，吃了就胖"

练后 30–60 分钟正是补充窗口，空腹硬熬更伤恢复。

✗
"减脂就要少吃肉"

蛋白质保肌肉，减脂期反而要吃够。

✗
"出汗多，灌瓶碳酸饮料就补回来了"

补水 + 电解质才是正解，碳酸饮料越喝越渴。

✗
"鸡蛋只吃蛋白，蛋黄扔掉"

蛋黄含健康脂肪和多种维生素，正常人吃全蛋没问题。

✗
"补剂吃越多，长得越快"

超量只增肝肾负担。科学的量 + 正常饮食才是关键。

✗
"赛前狂吃一顿攒能量"

能量靠平时和赛前 1 天储备，赛前大餐只会上场犯困。

✗
"光吃蛋白质就能长肌肉"

碳水 + 蛋白质协同才长肉，缺碳水等于白练。

✗
"零食热量不高，多吃没事"

零食是热量+糖+盐的空包，吃零食会挤占训练餐的份额。
