分时段饮食规则

什么时候吃，比吃什么更讲究。点卡片看实操细节。

🌅 晨训前

喝半杯水 + 半根香蕉或一片面包垫底。

晨跑先别空腹上大强度，低血糖又伤胃。醒了先补水，15 分钟后再垫两口碳水。

🍚 训练前 1–2 小时

以易消化碳水为主，七分饱。

面条、香蕉、全麦面包都行。别碰高油高脂——消化慢，练着恶心、状态掉。

🍌 训练前 30 分钟

香蕉半根 / 一片面包垫底。

空腹上大强度容易低血糖，速度课直接垮。垫一口碳水，精神头完全不一样。

💧 训练中

长距离大汗时小口补电解质水。

短训补水就够，别硬灌运动饮料——糖太多，喝了犯困。长时间耐力训练才需要补糖补电解质。

🥛 训练后 30 分钟内

碳水 + 蛋白一起吃，黄金窗口。

牛奶/乳清 + 香蕉/面包，蛋白补 20–30g。错过这个点，恢复肉眼可见地变慢。

🍳 休息日

三餐照常，蛋白质不能断。

别拿"今天不练"当胡吃海塞的借口。肌肉修复在休息日，蛋白吃不够等于白练一周。

📈 赛前 3 天

开始逐步加碳水，饮食清淡。

米饭、面、意面往上加，肉照吃。从今天起戒外卖炸物，让肠胃适应干净饮食。

🍚 赛前 1 天

高碳水储备，饮食清淡。

不碰陌生食物、不碰辛辣——肠胃是赛场的一部分。晚上好好睡，别熬夜啃夜宵。

🏁 比赛当日

赛前 3 小时吃完正餐。

赛前 1 小时只吃香蕉/面包这类好消化的，赛前 30 分钟小口补水。上场前肚子不能空，也不能胀。

🌙 夜宵（晚训后）

小份蛋白 + 少量碳水。

牛奶/酸奶 + 鸡蛋就够。拒绝油炸和烧烤——大半夜的油脂全存进腰上。

维持 / 增肌队员

  • 极端节食 = 自毁运动能力

  • 减脂永远是慢功夫，一周掉 0.5–1kg 是上限，稳着来

运动补剂简易科普

按国际运动营养学会（ISSN）、IOC 共识的 A/B/C 证据等级排序。先吃好饭，再谈补剂。

A 类 · 证据最强（ISSN/IOC 明确支持，值得优先）

🥤 咖啡因

A 类 · 耐力+爆发
3–6 mg/kg，赛前 30–60 分钟，提升爆发力和耐力表现。下午别喝，影响睡眠。

💪 肌酸

A 类 · 力量+爆发
3–5 g/天，短期可冲 20 g/天×5–7 天。最有把握的力量类补剂，肌肉增重是水不是脂肪。

⚡ β-丙氨酸

A 类 · 短时高强度
2–5 g/天，分次服。60–240 秒高强度项目（400米以上）提升肌肽缓冲酸，有刺痒感正常。

🥛 蛋白质粉（乳清/酪蛋白/大豆）

A 类 · 恢复
练后 20–40 g，适合日常肉没吃够的人。属于"吃饭的补充"，不是必须。

🧪 甜菜汁

A 类 · 耐力+摄氧
300–500 mg 硝酸盐/天，有氧耐力项目有证据支持，连用数周效果更稳。血压偏低者慎用。

🧂 碳酸氢钠

A 类 · 抗酸缓冲
0.2–0.3 g/kg，赛前 60–90 分钟。1–4 分钟全力项目（400–800米）可延缓酸疲劳，胃肠道反应大，先试。

B 类 · 条件支持（看情况用）

☀️ 维生素 D

B 类 · 日常保养
日晒不足者普遍偏低，补它保骨骼、护免疫。按需服用，别自己加量。

🐟 鱼油 / Omega-3

B 类 · 消炎恢复
每周 2–3 次深海鱼即可，鱼油作为补充。抗炎，配合消炎食物板块一起用。

🦴 氨糖软骨素

B 类 · 关节保养
膝盖、踝关节有磨损感的队员可长期吃。见效慢，坚持才有意义。

⚙️ 亮氨酸

B 类 · 蛋白合成触发
配合蛋白质一起用，单独吃意义不大。多吃肉蛋奶就行。

🧲 铁

B 类 · 仅缺铁人群
缺铁性贫血才补（尤其长跑、女队员），先查血再说，别乱补。

🍃 锌

B 类 · 免疫+恢复
运动员常见偏低，不足时补。过量反而伤吸收，按需。

C 类 · 证据弱 / 看个体（不优先）

🍶 支链氨基酸 BCAA

C 类 · 可被蛋白替代
练后乳清/食物蛋白已含足量 BCAA，单独补基本是智商税。

🌿 左旋肉碱

C 类 · 基本无效
减脂帮助有限，白花钱。

🔥 燃脂类（CLA/绿咖啡等）

C 类 · 证据不足
减脂靠热量缺口，别指望这些。

💧 电解质片

C 类 · 看情况
长时间大出汗或热天训练才需要，平时白水就够。

9

常见饮食误区

纠正认知，比多吃一口更重要。

✗
"不吃主食瘦得快"

碳水是运动燃料。断碳训练直接拉胯，成绩掉得比体重快。

✗
"练完不能吃饭，吃了就胖"

练后 30–60 分钟正是补充窗口，空腹硬熬更伤恢复。

✗
"减脂就要少吃肉"

蛋白质保肌肉，减脂期反而要吃够。

✗
"出汗多，灌瓶碳酸饮料就补回来了"

补水 + 电解质才是正解，碳酸饮料越喝越渴。

✗
"鸡蛋只吃蛋白，蛋黄扔掉"

蛋黄含健康脂肪和多种维生素，正常人吃全蛋没问题。

✗
"补剂吃越多，长得越快"

超量只增肝肾负担。科学的量 + 正常饮食才是关键。

✗
"赛前狂吃一顿攒能量"

能量靠平时和赛前 1 天储备，赛前大餐只会上场犯困。

✗
"光吃蛋白质就能长肌肉"

碳水 + 蛋白质协同才长肉，缺碳水等于白练。

✗
"零食热量不高，多吃没事"

零食是热量+糖+盐的空包，吃零食会挤占训练餐的份额。

1

力量训练

最大力量 → 爆发力 · 快速力量 → 核心 / 踝髋 / 小肌群。投掷的根基、速度的引擎、耐力的省能器。注意：小肌群不是只练小腿——核心、踝、髋、腘绳才是重点。

2

速度训练

位移速度是短跨跳的核心，中长跑需要的是"最后冲刺能力"，投掷不需要位移速度但极其需要"出手速度"——三种需求自动适配，别拿一套练三组人。

3

速耐训练

糖酵解供能：短跨跳的"后程不掉速"，中长跑的"乳酸耐受 + 速度保持"。强度高，恢复更要跟上。

4

耐力训练

有氧氧化供能：中长跑的主干，短跨跳 / 投掷的供能基础。别把短跑运动员练成马拉松选手——强度分层，各取所需。

5

柔韧 · 灵敏 · 基础体能

训练的热身与收尾，伤病的第一道防线。动态拉伸放练前、静态拉伸放练后，别搞反。

6

恢复与再生

训练给刺激，恢复给成绩。没有恢复就没有超量恢复——练得再狠，睡不够等于白练。

🚶 主动恢复

恢复日别躺平
20–30min 慢走 / 游泳 / 单车，促进血流带走代谢废物。躺着恢复反而更慢。

🧊 冷身

练完别立刻坐下
5–10min 慢跑 + 拉伸过渡，让心率平缓、乳酸排掉，是训练的一部分。

😴 睡眠

7–9h 是恢复主力
深睡期生长激素释放，肌肉修复就靠它。熬夜 = 今天的训练白练一半。

🧊 冷热交替 / 冰敷

大强度课后用
冰敷 5–10min 降炎症；日常冷热交替促循环。别把冰敷当日常水疗。

🧘 拉伸时机

动态练前、静态练后
训练前做静态拉伸会泄力；训练后静态拉伸放松。顺序别搞反。

🪨 泡沫轴 / 筋膜放松

滚大肌群 10min
大腿前后、臀部、背阔肌。比不滚强，但别指望它替代睡觉。

📈 疲劳监控

晨脉 + 主观疲劳感
连续几天晨脉偏高、身体发沉，说明负荷过载，该主动降量了。

一周训练安排（周期化）

按 准备期 / 竞赛期 给各组项目排一周微周期。先选上方项目，再切阶段。正式计划以教练安排为准，这只是参考骨架。

8

技术训练要点

体能是发动机，技术是变速箱。再强的力量，发不出力等于白搭。

⚡ 短跨跳

起跑 / 途中跑 / 跳跃

  • 起跑三要素：听到信号 → 蹬离起跑器 → 第一脚落地，前 10m 是决胜关键
  • 途中跑：摆动腿主动前摆下压，前脚掌落在重心投影下方
  • 跨栏：栏间步幅节奏固定，摆动腿膝盖领先、折叠过栏
  • 跳远踏跳：最后两步自然加速，踏跳脚全脚掌向前上方起跳
  • 跳高助跑：弧线助跑，起跳腿蹬伸充分、摆臂带起
🏃 中长跑

配速 / 摆臂 / 冲刺

  • 配速：起步压住、后半程发力，负分段是最高效跑法
  • 摆臂：前后摆、肘约 90°，别横摆浪费能量
  • 步频步幅：小步快频省能，最后冲刺才拉大步幅
  • 呼吸：2 步一吸、2 步一呼，节奏乱则配速崩
  • 最后冲刺：前 80% 稳住，把力气留给最后 200m
🏋️ 投掷

出手角度 / 发力顺序 / 鞭打链

  • 出手角度：铅球约 38–42°，标枪更平更低
  • 发力顺序：脚下蹬转 → 髋 → 躯干 → 肩 → 手，从下往上传导
  • 旋转 / 滑步：先慢后快，出手瞬间才是最快
  • 鞭打链：手腕最后发力，整条链像甩鞭子
  • 下肢为先：投掷靠腿不靠手，力量从地面借上来
9

训练误区 & 伤病预防

纠正认知，比多练一次更重要；预防伤病，比治疗伤病更划算。

🧠 训练误区
✗
"天天练最大速度 = 越快"

速度靠强度不靠量，组间恢复不足反而越练越慢。

✗
"力量训练会把跑者练笨练慢"

正确配比的力量让速度更快、伤病更少，不是对手。

✗
"小肌群训练 = 只练小腿"

核心、踝、髋、腘绳才是重点，小腿只是其中一环。

✗
"中长跑不需要力量训练"

核心 + 下肢力量帮你省能、防伤，最后冲刺更有力。

✗
"投掷练得越重越好"

技术 + 爆发力优先，大重量只是原料，出手速度才是产品。

✗
"大强度天天上 = 进步快"

没有恢复就没有超量恢复，只会越练越废。

✗
"恢复 = 躺床上就行"

主动恢复（慢走 / 游泳）+ 睡眠，效果远好于干躺着。

✓
"组间休息要够"

速度课、力量课组间歇足 2–3min，别怕"歇太久"——这是训练的一部分。

🩹 伤病预防

🦵 腘绳肌拉伤

练北欧弯举 + 离心
短跑 / 中长跑高发。每周 1–2 次北欧弯举，充分热身，疲劳态别冲大速度。

🦶 踝扭伤

踝泵 + 单腿平衡 + 落地技术
弹力带踝内外翻、闭眼单腿站，落地收紧踝关节，疲劳时别乱跳。

🦴 膝盖疼痛

股四头肌离心 + 力量渐进
保加利亚分腿蹲、靠墙静蹲；每周负荷别猛加（+10% 以内）。

🗼 下背不适

核心稳定 + 硬拉技术
深蹲硬拉全程收核心，重量一点点加，腰疼马上停。

🦴 应力性骨折

负荷渐进 + 疼痛即停
跑量每周增加不超过 10%，骨痛是警告信号，别硬扛。

🏃 跑者膝

臀中肌激活 + 髂胫束放松
弹力带髋外展、泡沫轴滚大腿外侧，改善跑姿。

10

训练 × 饮食联动

训练方案定下来，怎么吃就是配套工程。点按钮直接跳到饮食板块对应位置。

⚡ 高强度速度 / 速耐课

练前 1–2h 补碳水、练后 30min 蛋白 + 碳水，供能恢复两不误。

🏋️ 力量课

练后 30–60min 蛋白窗口，肌肉合成峰值，肌酸可作为辅助。

🏃 耐力课（>60min）

跑后补碳水 + 电解质，长距离人群注意补铁防贫血。

🏁 赛前

赛前 3 天逐步加碳水、比赛日饮食清淡，肠道也是赛场的一部分。

🔥 减脂期训练

蛋白只增不减、训练前后不断碳——减脂减的是脂肪不是成绩。

😴 恢复日

蛋白照吃别断、碳水适量。休息日不是放纵日，肌肉修复全靠它。
